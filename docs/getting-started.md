# Getting started

## Install

Download Conest for your system from the
[releases page](https://github.com/glitch-228/conest/releases):

- Android: the `.apk` file. Your phone may ask you to allow installs from
  the browser or file manager you opened it with.
- Linux: the `linux-x64` archive. Unpack it anywhere and run `conest`.
- Windows: the `windows-x64` archive. Unpack it anywhere and run
  `conest.exe`. Windows may ask to allow Conest through the firewall:
  allow it on private networks so devices nearby can reach you.

Conest updates itself (Settings > Updates). Updates are signed; Conest
refuses one whose signature does not match.

## Create your identity

On first start Conest asks for a display name. That is all: there is no
phone number, email address or account on a server. Your keys stay on
the device, in an encrypted vault.

Then choose how much of Conest to show:

- Minimal: chats only, large and simple.
- Standard: like the popular messengers.
- Advanced: everything, including how each message travelled.

You can change this later in Settings > Personal.

Next, Conest checks which ways to reach people work on the network you
are on, and offers to turn on the ones that do. Turn on at least one
(three are better). See [Reaching people](reaching-people.md).

## Add a contact

Conest has no directory: you add someone by exchanging an invite.

1. One of you opens Add contact and shows the QR code (or copies the
   invite text).
2. The other scans it (or pastes it) and sends the request.
3. The first accepts the request.

Nearby devices on the same network can also pair with a short codephrase.

## Groups

Create a group from the chat list and pick its members from your
contacts. Members you have not added yourself can be added as contacts
from the group's member list.

## Saved messages

Saved messages is a chat with yourself, pinned at the top, for notes and
things you forward to keep. If you link more devices to your account,
saved texts appear on each of them.
